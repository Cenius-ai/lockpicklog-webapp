# LockpickLog walkthrough - every command below runs the real CLI
# against a throwaway store at .demo-store/data.json

## help first

$ python3 lockpicklog.py --version
LockpickLog 1.0.0

$ python3 lockpicklog.py --help
usage: lockpicklog [-h] [--version] [--no-color] <command> ...

LockpickLog - log your locks, their pin stacks and your pick attempts.

positional arguments:
  <command>
    locks     log locks (model and picking method)
    pins      log a lock's pin tumbler sequence
    practice  time attempts and report your success rate

options:
  -h, --help  show this help message and exit
  --version   show program's version number and exit
  --no-color  disable ANSI colour (the NO_COLOR environment variable is also
              honoured)

examples:
  lockpicklog locks add --model "Master 140" --method rake --note "practice padlock"
  lockpicklog locks list
  lockpicklog locks show 1
  lockpicklog pins add 1 --position 1 --height 3 --note "low cut"
  lockpicklog pins show 1
  lockpicklog practice start 1
  lockpicklog practice stop --success
  lockpicklog practice stats --lock 1

store:
  lockpicklog keeps one JSON log. Default $HOME/.lockpicklog/data.json, overridden
  with the LOCKPICKLOG_DATA environment variable.

output:
  records go to stdout (one per line, safe to redirect), errors to stderr.
  Colour is only used on a terminal and is disabled by --no-color or NO_COLOR.

exit codes:
  0 success   2 bad input (nothing stored)   1 storage problem (nothing changed)

## 4. timed attempts

$ python3 lockpicklog.py practice start 1
timer running for lock 1 - Master 140 - session 1 started 2026-10-13T22:34:04+00:00 (stop it with: lockpicklog practice stop --success|--failure)

$ python3 lockpicklog.py practice stop --success
session 1 complete: opened in 2s for lock 1 - Master 140

$ python3 lockpicklog.py practice start 2
timer running for lock 2 - ABUS 55/40 - session 2 started 2026-10-13T22:34:06+00:00 (stop it with: lockpicklog practice stop --success|--failure)

$ python3 lockpicklog.py practice stop --failure
session 2 complete: not opened in 2s for lock 2 - ABUS 55/40

$ python3 lockpicklog.py practice stop --success
error: no timer is running - start one with: lockpicklog practice start [<lock_id>]; usage: lockpicklog practice stop --success|--failure
(exit 2 - nothing was stored)

$ python3 lockpicklog.py practice stats
